# OTP challenge
<!-- impeccable:product-schema 1 -->

## Platform
Android.

## Stack
Kotlin and Jetpack Compose, copied from the provided Android template.

## Purpose and constraints
Implement issue #1 as a local OTP demonstration for the hackathon. No real phone number, SMS provider or backend is required. The issue defines exact copy and behavior; README.md and RULES.md define submission requirements. All changes stay inside submissions/didahdx/. The supplied reference and assets are the visual authority. Users must be able to enter or paste a code, correct it, submit it and request another after 30 seconds; support screen readers, dark mode and the Android keyboard.
